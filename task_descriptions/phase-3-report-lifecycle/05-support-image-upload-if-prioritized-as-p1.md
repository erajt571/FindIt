# Support image upload if prioritized as P1

**Task group:** Phase 3: Report lifecycle

## Description

If P1 image support is approved, integrate the selected object-storage provider with safe file validation and metadata persistence. Keep image delivery and failure behavior aligned with report visibility and privacy rules.

## Completion outcome

When included, allowed file types and sizes are enforced, storage keys are not public by accident, and upload failures leave the report workflow usable.
