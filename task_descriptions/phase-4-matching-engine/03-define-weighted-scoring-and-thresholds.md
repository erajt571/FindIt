# Define weighted scoring and thresholds

**Task group:** Phase 4: Matching engine

## Description

Combine semantic description similarity with category, location, and date compatibility. Use the SRS's initial 60/20/10/10 weighting as a tunable starting point, not a validated accuracy claim, and apply the configured minimum threshold.

## Completion outcome

The initial weighting, normalization, threshold, and tuning caveat are documented and tested against representative positive and negative examples.
