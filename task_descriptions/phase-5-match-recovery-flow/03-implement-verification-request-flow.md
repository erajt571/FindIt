# Implement verification request flow

**Task group:** Phase 5: Match/recovery flow

## Description

Let a user ask the other report participant to verify a potential match, record the request state, and provide a controlled in-app contact process. Keep a suggested score explicitly advisory; do not treat it as proof of ownership or publish personal contact information.

## Completion outcome

Only eligible participants can initiate or respond to a request, request state is persisted, and the process does not expose private contact details or equate a match score with ownership.
