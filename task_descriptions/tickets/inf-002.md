# INF-002: Database migrations and seed strategy

**Priority:** P0  
**Depends on:** INF-001

## Description

Create the PostgreSQL schema for users, reports, matches, notifications, and the supporting records required by the agreed MVP. Use versioned migrations and deterministic, safe development/test fixtures.

## Acceptance summary

Schema creates from empty DB; repeatable seed

## Completion outcome

A clean database reaches the current schema through migrations, constraints are enforced, and the seed process can be repeated without duplicate or sensitive data.
