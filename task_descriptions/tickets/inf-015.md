# INF-015: Admin moderation and audit log

**Priority:** P1  
**Depends on:** INF-003/004

## Description

Provide minimal administrator tools to review reports and user-submitted complaints, remove inappropriate or suspicious listings, and suspend accounts when justified. Require a reason and record each action in a protected audit history.

## Acceptance summary

ADMIN-only actions require reasons and are logged

## Completion outcome

Only administrators can perform moderation actions, each action requires a reason, and actor, target, time, and reason are auditable.
