# INF-011: Persist match suggestions and deduplicate pairs

**Priority:** P0  
**Depends on:** INF-002/009

## Description

Persist qualifying suggestions with scores and explainable signals, and enforce idempotent pair creation when matching is retried or jobs are repeated.

## Acceptance summary

No duplicate pairs under repeated jobs

## Completion outcome

Suggestions can be retrieved after processing and repeat processing does not create duplicate report pairs.
