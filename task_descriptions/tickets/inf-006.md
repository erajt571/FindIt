# INF-006: Frontend shell, routing, design system

**Priority:** P0  
**Depends on:** INF-001

## Description

Create the Next.js client shell with shared navigation, routing, reusable visual foundations, configured API access, and common loading, empty, and error patterns.

## Acceptance summary

Responsive shared layout and error states

## Completion outcome

Core routes render in the shared responsive layout and users receive consistent feedback for loading and API failures.
