# INF-003: Authentication and current-user API

**Priority:** P0  
**Depends on:** INF-001/002

## Description

Implement the chosen secure authentication flow and expose the authenticated user's safe profile. Use the SRS roles USER and ADMIN, enforce role checks in the API, securely hash passwords, and keep credentials or tokens out of unsafe client storage as specified by the architecture decision.

## Acceptance summary

Register/login/logout; server-side role checks

## Completion outcome

Register, sign-in, sign-out, and current-user behavior work; anonymous and insufficiently privileged requests are rejected by the server.
