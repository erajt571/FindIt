# INF-014: Image upload pipeline

**Priority:** P1  
**Depends on:** INF-007

## Description

If prioritized after P0 reliability, integrate report-photo upload with managed object storage, server-side type and size checks, safe object access, and client preview and failure handling.

## Acceptance summary

Size/type limits, private keys, preview and failure UX

## Completion outcome

Unsupported or oversized files are rejected; storage metadata is persisted safely; upload failure does not prevent a user from understanding or managing the report.
