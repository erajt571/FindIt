# INF-010: Embedding provider adapter and job retry

**Priority:** P0  
**Depends on:** INF-009

## Description

Integrate embeddings behind a provider-neutral server-side interface and make asynchronous matching resilient to provider timeout and transient failure. Support deterministic local behavior for testing or demos.

## Acceptance summary

Timeout/retry/fallback behavior documented

## Completion outcome

Provider access is configurable without leaking secrets; retry and terminal-failure behavior is documented and tested; report persistence is not coupled to provider availability.
