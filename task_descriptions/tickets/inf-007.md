# INF-007: Report form and item detail UI

**Priority:** P0  
**Depends on:** INF-004/006

## Description

Build the user-facing report form and item detail experience, including validation feedback and authorized edit/status actions. Include optional image handling only if P1 image upload is prioritized.

## Acceptance summary

Create/detail/edit/status flows work

## Completion outcome

A user can create and inspect a report and use permitted edit/status actions; field errors and service failures are understandable.
