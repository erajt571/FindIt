# INF-008: Browse and dashboard UI

**Priority:** P0  
**Depends on:** INF-005/006

## Description

Implement the browse experience backed by API search/filter/pagination and a dashboard whose summaries are derived from authorized data rather than hard-coded demo counts.

## Acceptance summary

Data-driven search and dashboard metrics

## Completion outcome

Changing browse filters updates results predictably, and dashboard totals match the underlying permitted records.
