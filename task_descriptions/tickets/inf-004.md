# INF-004: Report CRUD and status transitions

**Priority:** P0  
**Depends on:** INF-002/003

## Description

Implement report creation, authorized detail retrieval, owner editing, and status transitions for LOST/FOUND reports. Validate the SRS-required item name, category, description, campus location, and incident date, with optional photograph and notes. Enforce ACTIVE, PENDING_VERIFICATION, and RESOLVED report states, and preserve report creation independently from later asynchronous matching.

## Acceptance summary

Validation, owner checks, correct state rules

## Completion outcome

API tests cover create/read/edit and valid/invalid transitions, enforce ownership, and confirm reports persist with valid data.
