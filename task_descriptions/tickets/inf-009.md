# INF-009: Matching domain service and deterministic tests

**Priority:** P0  
**Depends on:** INF-004

## Description

Create the backend matching domain service that selects plausible opposite-type active reports and ranks them using semantic description similarity, category compatibility, campus location, and date. Use the SRS's initial 60/20/10/10 weighting as a tunable starting point, not a validated accuracy claim.

## Acceptance summary

Correct candidate direction, ranking, thresholds

## Completion outcome

Automated tests cover candidate direction, eligibility, score ordering, and threshold boundaries without relying on a live AI provider.
