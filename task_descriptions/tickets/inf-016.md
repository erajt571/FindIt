# INF-016: Automated API/UI journey tests

**Priority:** P0  
**Depends on:** Core flows

## Description

Automate or establish a deterministic repeatable test for the key API and user-interface journey using two distinct users, from report submission to match verification and resolution.

## Acceptance summary

Two-user demo flow automated or documented as repeatable smoke test

## Completion outcome

The test or smoke procedure exercises both participant perspectives, persisted state, and key authorization boundaries and can be rerun by the team.
