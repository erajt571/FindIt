# INF-005: Browse/search/filter/pagination API

**Priority:** P0  
**Depends on:** INF-004

## Description

Build the report-discovery API with supported search and filters for relevant report attributes, plus stable, bounded pagination suitable for the browse experience.

## Acceptance summary

Filters combine correctly; bounded page size

## Completion outcome

Tests verify each filter and combinations, deterministic page behavior, authorization/visibility policy, and a server-enforced page-size ceiling.
