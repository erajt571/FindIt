# INF-013: In-app notifications

**Priority:** P0/P1  
**Depends on:** INF-011/012

## Description

Notify users about relevant suggestion and verification events with recipient-scoped access, duplicate protection, and read/unread behavior if included in the agreed MVP scope.

## Acceptance summary

Deduplicated, user-scoped, mark-read works

## Completion outcome

The intended events create notifications for the right users, repeated jobs do not spam duplicates, and recipients can view and mark their own notifications read.
