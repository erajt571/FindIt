# Confirm MVP scope and product definition

**Task group:** Phase 0: Kickoff & decisions

## Description

Agree which FindIt capabilities constitute the demonstrable MVP: accounts, lost/found reports, browse and search, advisory matches, and recovery status. Explicitly decide whether the SRS's Should Have items (in-app notifications, photo uploads, and basic moderation) fit the delivery; keep Could Have features outside the MVP unless separately approved.

## Completion outcome

A written scope lists included and excluded capabilities, resolves Must Have versus Should Have priorities, and defines an agreed end-to-end recovery journey.
